# Расширенный графический калькулятор на JavaFX

## Описание проекта
Расширенный графический калькулятор является дополненной версией базового проекта (проект №5), реализованный 
на JavaFX с использованием архитектуры MVC.
Проект представляет собой расширенный интерфейс калькулятора с добавлением истории операций и
новых арифметических операций

## Цели проекта
- Освоение MVC паттерна в контексте JavaFX приложений
- Углубление работы с JavaFX - FXML, обработка событий, многооконный интерфейс
- Реализация сложной бизнес-логики с расширенными математическими операциями
- Создание системы истории вычислений

## Функциональность
- Базовые операции (+, -, *, /)
- Работа с числами: ввод цифр, сброс, вычисление результата
- Расширенные математические операции: возведение в степень, корень n-ой степени, получение обратного числа
- Система истории вычислений
- Обработка ошибок в ходе вычислений

## Образовательные результаты
- Понимание принципов MVC в контексте JavaFX
- Навыки работы с FXML и Scene Builder
- Опыт связывания UI элементов с Java кодом
- Умение организовывать сложное состояние приложения
